agent-precheck | Refuse a run up front when the agent binary cannot be reached, instead of failing every task identically. Motivation, observed for real: an expired claude CLI OAuth session made a 2-task `yolotown run` burn one agent invocation and leave one orphaned worktree PER TASK, each failing with the same 'Failed to authenticate' error. At 50 tasks that is 50 wasted invocations and 50 worktrees. Add a single reachability probe to preflight — one per invocation, NOT per task — that runs CLAUDE_BIN with a trivial prompt and stdin redirected from /dev/null, before any worktree or run dir is created. Nonzero exit refuses the whole run, naming the likely cause (expired or missing session) and the exact fix (claude logout && claude login). It belongs in both entry paths (seed.sh and the yolotown entrypoint's cmd_run) — put it somewhere shared rather than writing it twice; lib/task.sh already holds the shared per-task core, so a sibling preflight helper is the natural home. CRITICAL CONSTRAINT, read before designing: tests/fake-claude is the CLAUDE_BIN seam, and tests/crash.test.sh sets FAKE_CLAUDE_MODE=crash expecting the run to still reach worktree creation and report a FAILED task with the worktree left intact for autopsy. If the probe simply invokes the shim, crash mode will fail the probe, the run will abort before creating anything, and that existing test breaks. Do NOT weaken or edit crash.test.sh to accommodate this — per SPEC.md section 4 a red gate means the work is wrong, not the test. Instead make the probe distinguishable in the shim, e.g. a separate FAKE_CLAUDE_PROBE_MODE that defaults to succeeding, so FAKE_CLAUDE_MODE keeps meaning 'how the task agent behaves' and is unaffected. Ship with tests covering both a reachable agent (run proceeds) and an unreachable one (run refuses, exit nonzero, no worktree and no run dir created, error names the fix).
fan-out | Implement bounded parallel workers via subshells honoring MAX_PARALLEL (with a --parallel N override and a --serial fallback), per-worker status files via lib/rundir.sh, and crash containment (one worker's crash never kills the run), followed by the fan-in report. See SPEC.md section 3.3. Tests must prove the concurrency bound using shim sleeps. Ship with tests.
