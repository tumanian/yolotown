cli | Implement the yolotown entrypoint with subcommand dispatch (plan, run, run-one, status, clean). `run` iterates a tasks file serially using lib/tasks.sh, continuing past individual task failures; `run-one` preserves today's single-task seed.sh behavior; `clean` prints worktree/branch removal commands and only executes them with --force. See SPEC.md section 2 for the final CLI surface. Ship with tests.

See SPEC.md section 3.3. Tests must prove the concurrency bound using shim sleeps. Ship with tests.
